Metodologi

  1. Rekonsiliasi jumlah closed trades dan observed terminal return antara Phase 2, Phase 3, dan bootstrap Phase 4.
  2. Untuk tujuh metrik deskriptif, hitung robust z = (x - median) / (1.4826 x MAD). Fallback IQR atau sample standard deviation digunakan hanya bila MAD nol.
  3. Magnitudo deviasi per timeframe adalah root-mean-square dari tujuh robust z. Share konsentrasi adalah magnitudo dibagi total magnitudo.
  4. HHI adalah jumlah kuadrat share; effective contributors adalah 1 / HHI. Tidak ada cutoff inferensial atau fungsi objektif.
  5. HTF Bias Timeframe dan Minimum Entry Score tidak diberi nilai performa, tidak diinterpolasi, dan tidak diranking karena outcome-tagged controlled runs tidak tersedia.
