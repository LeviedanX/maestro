Metodologi

1. Trade sequence permutation

Setiap path memakai seluruh N trade tepat satu kali tanpa replacement, tetapi urutannya diacak. Total PnL dan terminal return invariant; distribusi yang informatif adalah maximum drawdown, minimum equity, dan path-order risk.

2. IID bootstrap resampling

Setiap path mengambil N trade dari empirical PnL dengan replacement. Metode ini menghasilkan variasi komposisi, terminal return, dan drawdown. Percentile interval 95% adalah bootstrap interval conditional pada sample terobservasi dan asumsi IID.

3. Equity curve simulation

Untuk setiap sequence, equity dihitung sebagai initial capital ditambah cumulative PnL. Running peak menghasilkan maximum drawdown USD/persen; terminal equity menghasilkan return dan event return negatif.

Definisi statistik

  • Median/mean return: pusat distribusi terminal return dari seluruh simulated paths.
  • Percentile distribution: P1, P2.5, P5, P25, P50, P75, P95, P97.5, dan P99.
  • Worst/best case: minimum/maksimum hasil yang muncul di 10,000 simulasi; bukan batas populasi.
  • Maximum drawdown: penurunan terbesar dari running peak pada masing-masing path.
  • Probability of negative return: proporsi path dengan terminal PnL di bawah nol; resolusi simulasi 0.0100%.
  • Confidence interval: interval percentile 2.5%-97.5%. Untuk permutation, return interval degenerat secara matematis. Untuk bootstrap, istilah yang lebih tepat adalah nonparametric bootstrap percentile interval.

Asumsi dan keterbatasan

  1. Input berisi 323 processed rows: 322 closed, 1 open, dan 2 malformed rows dikarantina upstream.
  2. Trade-ID dan periode sumber tidak lengkap; simulated paths tidak mengisi observasi yang hilang.
  3. IID bootstrap mengabaikan serial dependence, volatility clustering, regime shifts, dan perubahan distribusi.
  4. Permutation mengubah urutan tetapi tidak mengubah frekuensi atau magnitudo PnL observed.
  5. Commission/slippage/feed/timezone tidak lengkap. Tidak ada cost stress tambahan.
  6. Initial capital 40 USD didukung export, tetapi masih berkonflik dengan deklarasi Pine 10,000.
  7. Interval simulasi bukan confidence statement tentang profitabilitas masa depan dan tidak boleh dipakai sebagai jaminan return.
